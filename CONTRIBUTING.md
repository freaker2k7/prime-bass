# Contributing to Prime Bass

Thank you for your interest in contributing to Prime Bass! We welcome contributions of all kinds,<br>
whether it's fixing bugs, adding new features, improving documentation, or suggesting ideas.

## How to Contribute

1. Fork the repository and create a new branch for your feature or bug fix.
2. Run `npm install` to install the dependencies.
3. Make your changes and work with `npm run dev` to test your changes locally.
4. Before submitting a pull request, please ensure your code is formatted with `npm run format`.
5. Also, make sure to run `npm run lint` to check for any linting errors.
6. Once you're ready, submit a pull request with a clear description of your changes and the problem it solves or the feature it adds.

Alternatively, if you have an idea or suggestion that you'd like to discuss before implementing, feel free to open an issue.

## Code of Conduct

Please note that this project is released with a Contributor Code of Conduct.<br>
By participating in this project, you agree to abide by its terms.<br>
You can find the code of conduct [here](https://github.com/freaker2k7/prime-bass?tab=coc-ov-file).
